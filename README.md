# Presentación CKD · versión 7 · stickers de UBC integrados

## Cómo abrir
Descomprime el ZIP completo en una carpeta y abre `index.html` con **Google Chrome** o Microsoft Edge. No necesitas Visual Studio Code ni conexión a internet para navegar el contenido local (salvo recursos externos preexistentes).

## Estructura
- `index.html`: archivo para visualizar la presentación.
- `app.js`: funcionalidades.
- `contenido.js`: datos de universidades y marcas.
- `style.css`: diseño.
- `fotos/stickers/tec/{licenciatura,maestria,doctorado}/`: 40 PNG.
- `fotos/restaurantes/`: 8 imágenes WEBP optimizadas, convertidas sin alterar su composición.
